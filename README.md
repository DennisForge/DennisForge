## 🌟 Featured Projects

### 🤖 [ML Product Category Classifier](https://github.com/DennisForge/ml-product-category-classifier)
Predicts a product's category from its title alone. Full ML pipeline: analysis, feature engineering, model comparison, training, and an interactive prediction script — built for real-world e-commerce classification.
`Python` `scikit-learn` `TF-IDF` `Jupyter`

### 💬 [ML Product Reviews — Sentiment Analysis](https://github.com/DennisForge/ml-product-reviews-project)
End-to-end sentiment classification of product reviews: data cleaning, feature engineering, model training, and evaluation on real, messy text.
`Python` `NLP` `Jupyter`

### ☁️ [AWS ATP Pipeline](https://github.com/DennisForge/aws-atp-pipeline)
Serverless ETL pipeline that automates ATP tennis data collection and analysis — Lambda functions on an EventBridge schedule, S3 storage, Kaggle API with Secrets Manager for credentials.
`AWS Lambda` `S3` `EventBridge` `Python`

### 🎬 [Movie IMDb API Project](https://github.com/DennisForge/movie-imdb-api-project)
Enriches a movie dataset via the OMDb API — fetches IMDb ratings, actors, and vote counts, then exports structured XML for analysis.
`Python` `REST APIs` `XML`
